# Tally

A shared household expense tracker for two people, in a single HTML file.

## Features
- Monthly dashboard: income, savings, total spent, remaining budget
- 30% savings goal (adjustable), with warnings when spending eats into it
- Budgets per category, flagged when over
- Add and edit expenses: amount, category, date, note, who paid, split (equal, one person, or custom %)
- Recurring expenses (rent, bills) added automatically each month
- Split & settle: running balance between the two of you, with payment records
- Search and filter transactions by category, person and date range

## Use it
Open `index.html` in any modern browser. No install or server needed.

Data is saved in your browser (localStorage) on that device only. Use **Settings → Download backup** to keep a copy or move it to another device.
